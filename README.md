# swedish-business-market-entry-corpus
Open B2B RAG &amp; knowledge dataset on Swedish market entry, corporate law (Aktiebolag/Bolagsverket), K3 accounting, tax/VAT compliance (Skatteverket), labor law (LAS), customs, and localization (2,000+ guides &amp; 13 advisory pillars) by CE Sweden (https://www.ce.se/).
